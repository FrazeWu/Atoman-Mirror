以下为 Debian 12 Bookworm 的 APT 源配置。

APT 地址mirror.atoman.org/debian/

配置 APT

01

临时使用

不改系统源，使用临时列表更新一次索引。

list=$(mktemp)
trap 'rm -f "$list"' EXIT
cat > "$list" <<'EOF'
deb https://mirror.atoman.org/debian/ bookworm main contrib non-free non-free-firmware
deb https://mirror.atoman.org/debian/ bookworm-updates main contrib non-free non-free-firmware
deb https://mirror.atoman.org/debian-security/ bookworm-security main contrib non-free non-free-firmware
EOF
sudo apt-get -o Dir::Etc::sourcelist="$list" -o Dir::Etc::sourceparts="-" update

写入配置文件

适用于 Debian 12，先备份现有主源文件再替换。

sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
sudo tee /etc/apt/sources.list >/dev/null <<'EOF'
deb https://mirror.atoman.org/debian/ bookworm main contrib non-free non-free-firmware
deb https://mirror.atoman.org/debian/ bookworm-updates main contrib non-free non-free-firmware
deb https://mirror.atoman.org/debian-security/ bookworm-security main contrib non-free non-free-firmware
EOF
sudo apt update

验证与恢复

02

本页命令适用于 Debian 12 (Bookworm)。先保留自动创建的 sources.list.bak；执行 sudo apt update 验证，恢复时将该备份还原为 /etc/apt/sources.list。
