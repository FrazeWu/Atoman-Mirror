Ubuntu

公开服务

以下为 Ubuntu 24.04 LTS 的 APT 源配置。

APT 地址mirror.atoman.org/ubuntu/

配置 APT

01

临时使用

不改系统源，使用临时列表更新一次索引。

list=$(mktemp)
trap 'rm -f "$list"' EXIT
cat > "$list" <<'EOF'
deb https://mirror.atoman.org/ubuntu/ noble main restricted universe multiverse
deb https://mirror.atoman.org/ubuntu/ noble-updates main restricted universe multiverse
deb https://mirror.atoman.org/ubuntu-security/ noble-security main restricted universe multiverse
EOF
sudo apt-get -o Dir::Etc::sourcelist="$list" -o Dir::Etc::sourceparts="-" update

写入配置文件

适用于 Ubuntu 24.04，将当前官方源文件替换为本站镜像。

sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak
sudo tee /etc/apt/sources.list.d/ubuntu.sources >/dev/null <<'EOF'
Types: deb
URIs: https://mirror.atoman.org/ubuntu/
Suites: noble noble-updates
Components: main restricted universe multiverse

Types: deb
URIs: https://mirror.atoman.org/ubuntu-security/
Suites: noble-security
Components: main restricted universe multiverse
EOF
sudo apt update

验证与恢复

02

本页命令适用于 Ubuntu 24.04 (Noble)。先保留自动创建的 .bak 备份；执行 sudo apt update 验证，恢复时将 ubuntu.sources.bak 还原为 ubuntu.sources。
