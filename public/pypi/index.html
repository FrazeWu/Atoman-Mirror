ATOMAN / MIRROR

PyPI

公开服务

适用于 pip 与兼容 PyPI 的工具。

索引地址mirror.atoman.org/pypi/simple

配置 pip

01

临时使用

只对当前安装命令生效。

python -m pip install --index-url https://mirror.atoman.org/pypi/simple package-name

写入配置文件

写入当前用户的 pip 配置。

mkdir -p ~/.config/pip
cat > ~/.config/pip/pip.conf <<'EOF'
[global]
index-url = https://mirror.atoman.org/pypi/simple
EOF

验证与恢复

02

适用于 pip 及兼容 PyPI 的工具。执行 python -m pip install --index-url https://mirror.atoman.org/pypi/simple pip 可验证；删除 ~/.config/pip/pip.conf 中的 index-url 即可恢复。
