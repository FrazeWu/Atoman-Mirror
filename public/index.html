ATOMAN / MIRROR

Docker Hub

公开服务

为 Docker Hub 配置镜像地址。

镜像地址https://mirror.atoman.org

配置 Docker daemon

01

临时使用

不修改 Docker daemon，直接使用镜像完整地址。

docker pull mirror.atoman.org/library/alpine:latest

写入配置文件

让 Docker Hub 拉取默认通过本站镜像。

sudo install -d -m 0755 /etc/docker
sudo tee /etc/docker/daemon.json >/dev/null <<'EOF'
{
  "registry-mirrors": ["https://mirror.atoman.org"]
}
EOF
sudo systemctl restart docker

ATOMAN / MIRROR

GitHub Container Registry

公开服务

通过本站拉取公开 GHCR 镜像。

镜像前缀mirror.atoman.org/ghcr.io

拉取镜像

01

临时使用

单次拉取时替换镜像前缀。

docker pull mirror.atoman.org/ghcr.io/owner/image:tag

写入配置文件

在项目的 compose.yaml 中固定镜像地址。

services:
  app:
    image: mirror.atoman.org/ghcr.io/owner/image:tag

私有镜像需要凭据，当前未开放。

ATOMAN / MIRROR

PyPI

公开服务

适用于 pip 与兼容 PyPI 的工具。

索引地址mirror.atoman.org/pypi/simple

配置 pip

01

临时使用

只对当前安装命令生效。

python -m pip install --index-url https://mirror.atoman.org/pypi/simple package-name

写入配置文件

写入当前用户的 pip 配置。

mkdir -p ~/.config/pip
cat > ~/.config/pip/pip.conf <<'EOF'
[global]
index-url = https://mirror.atoman.org/pypi/simple
EOF

ATOMAN / MIRROR

npm

公开服务

适用于 npm、pnpm 与 Yarn Classic。

Registry 地址mirror.atoman.org/npm/

配置 registry

01

临时使用

只对当前安装命令生效。

npm install --registry=https://mirror.atoman.org/npm/ package-name

写入配置文件

写入当前用户的 ~/.npmrc。

cat > ~/.npmrc <<'EOF'
registry=https://mirror.atoman.org/npm/
EOF

ATOMAN / MIRROR

Go Modules

公开服务

模块代理与校验数据库均经过本站，保留默认完整性校验。

模块代理mirror.atoman.org/go

配置 Go 环境

01

临时使用

仅对当前终端命令生效。

GOPROXY=https://mirror.atoman.org/go,direct \
GOSUMDB="sum.golang.org https://mirror.atoman.org/gosumdb" \
go install example.com/module@latest

写入配置文件

由 Go 写入 GOENV 指向的用户配置文件。

go env -w GOPROXY=https://mirror.atoman.org/go,direct
go env -w GOSUMDB="sum.golang.org https://mirror.atoman.org/gosumdb"

ATOMAN / MIRROR

Ubuntu

公开服务

以下为 Ubuntu 24.04 LTS 的 APT 源配置。

APT 地址mirror.atoman.org/ubuntu/

配置 APT

01

临时使用

不改系统源，使用临时列表更新一次索引。

list=$(mktemp)
trap 'rm -f "$list"' EXIT
cat > "$list" <<'EOF'
deb https://mirror.atoman.org/ubuntu/ noble main restricted universe multiverse
deb https://mirror.atoman.org/ubuntu/ noble-updates main restricted universe multiverse
deb https://mirror.atoman.org/ubuntu-security/ noble-security main restricted universe multiverse
EOF
sudo apt-get -o Dir::Etc::sourcelist="$list" -o Dir::Etc::sourceparts="-" update

写入配置文件

适用于 Ubuntu 24.04，将当前官方源文件替换为本站镜像。

sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak
sudo tee /etc/apt/sources.list.d/ubuntu.sources >/dev/null <<'EOF'
Types: deb
URIs: https://mirror.atoman.org/ubuntu/
Suites: noble noble-updates
Components: main restricted universe multiverse

Types: deb
URIs: https://mirror.atoman.org/ubuntu-security/
Suites: noble-security
Components: main restricted universe multiverse
EOF
sudo apt update

Debian

公开服务

以下为 Debian 12 Bookworm 的 APT 源配置。

APT 地址mirror.atoman.org/debian/

配置 APT

01

临时使用

不改系统源，使用临时列表更新一次索引。

list=$(mktemp)
trap 'rm -f "$list"' EXIT
cat > "$list" <<'EOF'
deb https://mirror.atoman.org/debian/ bookworm main contrib non-free non-free-firmware
deb https://mirror.atoman.org/debian/ bookworm-updates main contrib non-free non-free-firmware
deb https://mirror.atoman.org/debian-security/ bookworm-security main contrib non-free non-free-firmware
EOF
sudo apt-get -o Dir::Etc::sourcelist="$list" -o Dir::Etc::sourceparts="-" update

写入配置文件

适用于 Debian 12，先备份现有主源文件再替换。

sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
sudo tee /etc/apt/sources.list >/dev/null <<'EOF'
deb https://mirror.atoman.org/debian/ bookworm main contrib non-free non-free-firmware
deb https://mirror.atoman.org/debian/ bookworm-updates main contrib non-free non-free-firmware
deb https://mirror.atoman.org/debian-security/ bookworm-security main contrib non-free non-free-firmware
EOF
sudo apt update
