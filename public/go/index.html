ATOMAN / MIRROR

Go Modules

公开服务

模块代理与校验数据库均经过本站，保留默认完整性校验。

模块代理mirror.atoman.org/go

配置 Go 环境

01

临时使用

仅对当前终端命令生效。

GOPROXY=https://mirror.atoman.org/go,direct \
GOSUMDB="sum.golang.org https://mirror.atoman.org/gosumdb" \
go install example.com/module@latest

写入配置文件

由 Go 写入 GOENV 指向的用户配置文件。

go env -w GOPROXY=https://mirror.atoman.org/go,direct
go env -w GOSUMDB="sum.golang.org https://mirror.atoman.org/gosumdb"

验证与恢复

02

保留 sum.golang.org 的完整性校验。执行 go env GOPROXY GOSUMDB 确认配置；使用 go env -u GOPROXY GOSUMDB 可恢复 Go 默认设置。
