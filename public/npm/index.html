ATOMAN / MIRROR

npm

公开服务

适用于 npm、pnpm 与 Yarn Classic。

Registry 地址mirror.atoman.org/npm/

配置 registry

01

临时使用

只对当前安装命令生效。

npm install --registry=https://mirror.atoman.org/npm/ package-name

写入配置文件

写入当前用户的 ~/.npmrc。

cat > ~/.npmrc <<'EOF'
registry=https://mirror.atoman.org/npm/
EOF

验证与恢复

02

仅代理公开 npm 包。用 npm view npm --registry=https://mirror.atoman.org/npm/ 验证；删除 ~/.npmrc 中的 registry 配置即可恢复默认 registry。
